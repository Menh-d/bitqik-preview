    ໜ້າທີ່ຮັບຜິດຊອບ

    • ຮັບຜິດຊອບວຽກງານ ກ່ຽວກັບບັນດາ ນິຕິກຳຕ່າງໆ, ການຮ່າງລະບຽບການຕ່າງໆ, ການຮ່າງສັນຍາ, ດັດແກ້ສັນຍາຕ່າງໆ ທີ່ນຳໃຊ້ ແລະ ກ່ຽວພັນກັບການດໍາເນີນທຸລະກິດ ຂອງບໍລິສັດ ທັງພາຍໃນ ແລະ ພາຍນອກ ບໍລິສັດ;
    • ຮັບຜິດຊອບວຽກງານ ແກ້ໄຂຂໍ້ຂັດແຍ່ງ, ຄະດີຄວາມ, ເອກະສານ ທີ່ກ່ຽວພັນກັບການຮ້ອງຟ້ອງ;
    • ດຳເນີນຄະດີຄວາມຕ່າງໆ ພ້ອມທັງຕິດຕາມການຮ້ອງຟ້ອງ, ຄະດີທີ່ຢູ່ໃນທຸກຂັ້ນຕອນຂອງເຈົ້າໜ້າທີ່ຕໍາຫຼວດ, ສານ, ໄອຍະການ ແລະ ຫ້ອງການຈັດຕັ້ງປະຕິບັດຄຳຕັດສິນຂອງສານ;
    • ໃຫ້ຄຳເຫັນ ຫຼື ຄໍາແນະນຳ ທາງດ້ານລະບຽບກົດໝາຍ, ນິຕິກຳຕ່າງໆ, ການປະຕິບັດຕາມລະບຽບການ, ການຕ້ານການຟອກເງິນ ແລະ ການສະໜອງທຶນແກ່ການກໍ່ການຮ້າຍ (AML) ທີ່ກ່ຽວຂ້ອງກັບການປະຕິບັດວຽກງານຂອງບໍລິສັດ ເພື່ອໃຫ້ດຳເນີນໄປຢ່າງຖືກຕ້ອງ;
    • ຜັນຂະຫຍາຍແຈ້ງການ ກ່ຽວກັບການປະຕິບັດບັນດານິຕິກຳຕ່າງໆ ທີ່ອອກໂດຍທະນາຄານແຫ່ງ ສປປ ລາວ ແລະ ພາກສ່ວນອື່ນທີ່ກ່ຽວຂ້ອງ ກັບການດໍາເນີນທຸລະກິດຂອງບໍລິສັດ;
    • ຮັບຜິດຊອບ ແລະ ຈັດຕັ້ງວຽກງານ ການຕ້ານການຟອກເງິນ ແລະ ການສະໜອງທຶນແກ່ການກໍ່ການຮ້າຍ (AML) ພ້ອມທັງເປັນເຈົ້າການໃນການພົວພັນ, ພ້ອມທັງ ພົວພັນປະສານ ກັບສຳນັກງານຕ້ານການຟອກເງິນ ແລະ ການສະໜອງທຶນໃຫ້ແກ່ການກໍ່ການຮ້າຍ ທະນາຄານແຫ່ງ ສປປ ລາວ ກ່ຽວກັບການຈັດຕັ້ງ ແລະ ການປະຕິບັດ;
    • ປະສານພົວພັນ ສຳນັກງານຂໍ້ມູນຕ້ານການຟອກເງິນ, ທະນາຄານແຫ່ງ ສປປ ລາວ ແລະ ພາກສ່ວນທີ່ກ່ຽວຂ້ອງ ໃນການຄົ້ນຄວ້າ, ສ້າງ, ທົບທວນ, ປັບປຸງ ຫຼື ດັດແກ້ ບັນດານິຕິກຳ ແລະ ເຄື່ອງມືກ່ຽວກັບ ການຕ້ານການຟອກເງິນ ແລະ ການສະໜອງທຶນໃຫ້ແກ່ການກໍ່ການຮ້າຍ;
    • ວິເຄາະຂໍ້ມູນທີ່ສົງໄສວ່າ ເປັນການຟອກເງິນ ແລະ ການສະໜອງທຶນໃຫ້ແກ່ການກໍ່ການຮ້າຍ ພ້ອມທັງລາຍງານຕໍ່ສຳນັກງານຂໍ້ມູນຕ້ານການຟອກເງິນ, ທະນາຄານແຫ່ງ ສປປ ລາວ;
    • ຕິດຕໍ່ພົວພັນ, ປະສານວຽກ ກັບບັນດາບໍລິສັດ, ຄູ່ຮ່ວມທຸລະກິດ ພາຍໃນປະເທດ ແລະ ຕ່າງໆປະເທດ ກ່ຽວກັບວຽກງານນິຕິກໍາ ແລະ ວຽກງານທີ່ກ່ຽວຂ້ອງ;
    • ຮັບຜິດຊອບ ແລະ ຈັດຕັ້ງປະຕິບັດ ວຽກງານການປະຕິບັດຕາມລະບຽບການຕ່າງໆ ທີ່ທະນາຄານແຫ່ງ ສປປ ລາວ ແລະ ພາກສ່ວນອື່ນທີ່ກ່ຽວຂ້ອງ ກຳນົດອອກ ແຕ່ລະໄລຍະ.

    ເງື່ອນໄຂຜູ້ສະໝັກ

    • ລະດັບການສຶກສາ ປະລິນຍາຕີຂຶ້ນໄປ ໃນສາຂາວິຊາສະເພາະ ກົດໝາຍ ( ກົດໝາຍພົວພັນສາກົນ, ກົດໝາຍທຸລະກິດ, ກົດໝາຍແພ່ງ, ກົດໝາຍອາຍາ, ກົດໝາຍປົກຄອງ ) ແລະ ກົດໝາຍອື່ນໆທີ່ກ່ຽວຂ້ອງ;
    • ມີປະສົບການເຮັດວຽກ (ຢ່າງໜ້ອຍ 01 ປີ ຂື້ນໄປ) ທາງດ້ານກົດໝາຍ, ນິຕິກຳລຸ່ມກົດໝາຍ, ວຽກງານທາງດ້ານຄະດີຄວາມ, ວຽກງານປະຕິບັດຕາມລະບຽບການ, ວຽກງານຕ້ານການຟອກເງິນ ແລະ ການສະໜອງທຶນແກ່ການກໍ່ການຮ້າຍ (AML);
    • ມີຄວາມຮູ້ທາງດ້ານ ພາສາອັງກິດ ຫຼື ພາສາຕ່າງປະເທດ ອື່ນໆ ໃນລະດັບກາງ ຫາ ລະດັບທີ່ດີ ( ທີ່ສາມາດສື່ສານ,ອ່ານ-ຂຽນ ເຂົ້າໃຈໄດ້);
    • ສາມາດນຳໃຊ້ຄອມພິວເຕີ ແລະ ໂປຣແກຣມຕ່າງໆ ໄດ້ເປັນຢ່າງດີ;
    • ມີພາວະເປັນຜູ້ນຳ, ມີຫົວຄິດປະດິດສ້າງ, ສຶກສາຄົ້ນຄ້ວາ ແລະ ພັດທະນາຕົນເອງ ຢູ່ເລື້ອຍໆ;
    • ມີຄວາມກະຕືລືລົ້ນ ໃນການເຮັດວຽກ, ມີວິໄນ, ຊື່ສັດ, ມີຄວາມຮັບຜິດຊອບຕໍ່ວຽກງານ, ດຸໝັ່ນ, ອົດທົນ, ສາມາດເຮັດວຽກເປັນທີມ ແລະ ສາມາດເຮັດວຽກ ພາຍໃຕ້ຄວາມກົດດັນໄດ້;

      • ວິເຄາະຂໍ້ມູນ Log / Application Data: ເພື່ອຊອກຫາຮູບແບບ (Pattern) ຂອງບັນຫາ.

      2) ອອກແບບ Dashboard/KPI/KRI ສໍາລັບຕິດຕາມ (Monitoring) ຄວາມສ່ຽງດ້ານລະບົບ (System Risk).

      • ພັດທະນາ ແລະ ເບິ່ງແຍງ Dashboard ສຳລັບ KPI / KRI ເຊັ່ນ:
      • MTTR (Mean Time to Resolve): ເວລາສະເລ່ຍໃນການແກ້ໄຂບັນຫາ.
      • MTBF (Mean Time Between Failure): ໄລຍະເວລາສະເລ່ຍກ່ອນການເກີດຄວາມຜິດພາດຄັ້ງຕໍ່ໄປ.
      • System Availability (ຄວາມພ້ອມໃຊ້ງານຂອງລະບົບ)
      • Alert Frequency (ຄວາມຖີ່ຂອງການແຈ້ງເຕືອນ) / Frequency of System Alerts (ຄວາມຖີ່ຂອງການແຈ້ງເຕືອນຈາກລະບົບ)
      • Error Rate (ອັດຕາການເກີດຄວາມຜິດພາດ)
      • Number of Incidents (ຈຳນວນເຫດການທີ່ເກີດຂຶ້ນ).
      • High CPU/Memory Threshold (ການກວດສອບການໃຊ້ງານຊັບພະຍາກອນລະບົບທີ່ສູງເກີນກຳນົດ).
      • ສ້າງ Dashboard ດ້ວຍເຄື່ອງມື Power BI, Tableau, Grafana ຫຼື Superset.

      3) ເຊື່ອມຕໍ່ຂໍ້ມູນຈາກຫຼາຍແຫຼ່ງ: ເຊັ່ນ: ລະບົບຫຼັກ (Core System), Database, Cloud Logs…Data Science

      4) ວິເຄາະສາເຫດທີ່ແທ້ຈິງ (Root Cause): ໃຫ້ຂໍ້ມູນສະໜັບສະໜູນການຕັດສິນໃຈຂອງທີມ Risk ແລະ ທີມ IT Cybersecurity.

      5) ເຮັດ Data Validation: ກວດສອບຄວາມຖືກຕ້ອງຂອງຂໍ້ມູນຈາກລະບົບຕ່າງໆ.

      6) ເຮັດວຽກຮ່ວມກັບທີມ IT / DevOps / Cybersecurity

      • ວິເຄາະ Log ແລະ ຂໍ້ມູນຈາກລະບົບ IT ເພື່ອຊອກຫາຄວາມສ່ຽງທີ່ອາດຈະເກີດຂຶ້ນ.
      • ສະໜັບສະໜູນທີມ ໃນການປະເມີນຄວາມສ່ຽງ (RCSA) ໂດຍການນຳໃຊ້ຂໍ້ມູນປະກອບການປະເມີນ System Risk.
      • ກວດສອບຂໍ້ມູນຈາກລະບົບຫຼັງການ Deploy/Update ເພື່ອປະເມີນຄວາມສ່ຽງດ້ານການປ່ຽນແປງ (Change Risk).

      7) ການບໍລິຫານຈັດການຂໍ້ມູນ (Data Management)

      • ເຮັດ Data Cleaning / Data Quality Validation ເພື່ອໃຫ້ຂໍ້ມູນມີຄວາມຖືກຕ້ອງ ແລະ ສາມາດນຳໄປໃຊ້ປະເມີນຄວາມສ່ຽງໄດ້ຢ່າງຊັດເຈນ.
      • ອອກແບບ Query / Script ສຳລັບດຶງຂໍ້ມູນແບບລາຍວັນ / ລາຍອາທິດ / ລາຍເດືອນ / ລາຍໄຕມາດ / ລາຍປີ.
      • ສ້າງລະບົບ Automation (ອັດຕະໂນມັດ) ໃນການປະມວນຜົນຂໍ້ມູນ.

      8) ສະໜັບສະໜູນການສ້າງລາຍງານຄວາມສ່ຽງ ແລະ ການປະເມີນຄວາມສ່ຽງ:

      • ການເຮັດ Risk Assessment / Risk & Control Self-Assessment (RCSA) ດ້ານ System & Technology
      • ສ້າງລາຍງານ Incident Report / Trend Analysis / Early Warning Indicator (ຕົວຊີ້ບອກເຕືອນໄພລ່ວງໜ້າ) ແບບລາຍວັນ / ລາຍອາທິດ / ລາຍເດືອນ / ລາຍໄຕມາດ / ລາຍປີ ເຊັ່ນ: ກວດສອບ ແລະ ກວດຈັບຂໍ້ມູນທີ່ຜິດປົກກະຕິ (Anomaly), ວິເຄາະແນວໂນ້ມ (Trend), ສະຫຼຸບເຫດການ ແລະ ເຮັດ Data Reconciliation
      • ສ້າງລາຍງານ Data Risk Dashboard, ສະໜັບສະໜູນການເຮັດ RCSA / Risk Assessment ແລະ ທົບທວນ (Review) KRI (ຕົວຊີ້ບອກຄວາມສ່ຽງຫຼັກ)
      • ສ້າງລາຍງານ Risk Dashboard ສຳລັບ RMC (ຄະນະກໍາມະການຄຸ້ມຄອງຄວາມສ່ຽງ), CEO ແລະ CTO.
      • ສະໜອງຂໍ້ມູນໃຫ້ແກ່ຄະນະກໍາມະການຄຸ້ມຄອງຄວາມສ່ຽງ (RMC) ເພື່ອນຳໃຊ້ໃນການກຳນົດ Risk Appetite (ລະດັບຄວາມສ່ຽງທີ່ຍອມຮັບໄດ້) & Threshold (ຂອບເຂດຄວາມສ່ຽງ).
      • ເຂົ້າໃຈຕົວເລກທຸລະກິດ ເຊັ່ນ: Revenue / Cost: ລາຍຮັບ ແລະ ຕົ້ນທຶນ, Transaction Volume: ປະລິມານການເຮັດທຸລະກຳ, Active Users: ຈຳນວນຜູ້ໃຊ້ງານທີ່ມີການເຄື່ອນໄຫວ, Liquidity / Exposure: ສະພາບຄ່ອງ ແລະ ລະດັບຄວາມສ່ຽງໃນການສູນເສຍ (ການເປີດຮັບຄວາມສ່ຽງ).
